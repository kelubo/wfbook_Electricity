# 串口

[TOC]

## 概述

**串口**（Serial Port）即串行通信接口，是最早、使用最久的一种板间 / 设备间通信接口。广义的"串口"涵盖 RS-232 、 RS-485 、 I²C 、 SPI 、 USB 等串行总线标准；狭义上，日常所说的"串口"通常指 **UART（通用异步收发器）** 通信，采用 RS-232 或 TTL/CMOS 电平。

---

## 基本概念

### 串行通信与并行通信

| 特性 | 串行通信 | 并行通信 |
|------|---------|---------|
| 数据线 | 1 条（或 1 对差分线） | 多条（8/16/32 位） |
| 传输方式 | 逐位顺序发送 | 多位同时发送 |
| 速度 | 随频率提升可达 Gbps | 高频时易受串扰影响 |
| 距离 | 可达数百 ~ 上千米 | 仅短距离（如板内） |
| 成本 | 线缆少，成本低 | 线缆多，成本高 |
| 典型应用 | 设备间通信 | 并口硬盘（IDE）、并口打印机 |

### 同步与异步通信

| 特性 | 同步通信 | 异步通信（UART） |
|------|---------|----------------|
| 时钟线 | 需要独立的时钟信号线 | 不需要时钟线 |
| 数据帧 | 连续比特流 | 按字符帧分隔 |
| 开销 | 低（无起始/停止位） | 高（每字节 2 ~ 3 位开销） |
| 典型协议 | SPI、I²S | UART、RS-232 |

### 单工 / 半双工 / 全双工

| 模式 | 发送方向 | 例子 |
|------|---------|------|
| 单工 (Simplex) | 单向，不可逆 | 收音机广播 |
| 半双工 (Half-duplex) | 双向但不能同时 | RS-485 两线制、对讲机 |
| 全双工 (Full-duplex) | 双向同时进行 | RS-232 三线、电话 |

## UART 帧格式

异步串口通信以 **帧 (frame)** 为单位传输数据。一帧包含：

```
[起始位] [数据位 0~7] [校验位(可选)] [停止位]
```

### 帧结构详解

1. **起始位**：1 位，逻辑 0（将空闲的 1 电平拉低），标志一帧的开始
2. **数据位**：5 ~ 9 位可选（常用 8 位），LSB（最低位）先发送
3. **校验位**（可选）：
   - 无校验 (None)
   - 奇校验 (Odd)：数据 + 校验位中 1 的个数为奇数
   - 偶校验 (Even)：数据 + 校验位中 1 的个数为偶数
   - 标记 (Mark)：校验位恒为 1
   - 空格 (Space)：校验位恒为 0
4. **停止位**：1 位、1.5 位或 2 位，逻辑 1

### 波特率

两边设备必须以相同的波特率通信。**波特率 = 每秒传送的符号数**，在二进制调制中等于比特率（bps）。

常用波特率：

| 速率 | 说明 |
|------|------|
| 300 | 极低速率，早期调制解调器 |
| 1200 | |
| 2400 | |
| 4800 | |
| 9600 | 常用默认值 |
| 14400 | |
| 19200 | |
| 38400 | |
| 57600 | |
| 115200 | 最常用高速 |
| 230400 | |
| 460800 | |
| 921600 | 高速 USB 转串口 |

**波特率误差容忍**：UART 的接收端通过过采样（通常 16 倍波特率时钟）确定每位的中间位置，一般可容忍约 2% ~ 5% 的波特率偏差（偏差过大会导致错位）。

## 电平标准

UART 只有"电平标准"不同，协议帧格式完全相同。常见电平有：

### TTL / CMOS 电平（板级通信）

- 逻辑 1：VCC（3.3 V 或 5 V）
- 逻辑 0：GND（0 V）
- 典型用于 MCU 与模块直连

### RS-232 电平

- 逻辑 1：−3 V ~ −15 V（Mark）
- 逻辑 0：+3 V ~ +15 V（Space）
- 使用 **MAX232** 等电平转换芯片在 TTL 与 RS-232 间互转

### RS-485 差分电平

参见 [RS-485](RS485.md) 文件。

## 电平转换芯片

| 芯片 | 功能 | 通道数 | 典型应用 |
|------|------|--------|---------|
| MAX232 / SP232 | TTL ⇄ RS-232 | 2 发 2 收 | 单片机接入 PC 串口 |
| MAX3232 | TTL (3.3V) ⇄ RS-232 | 2 发 2 收 | 低电压版 MAX232 |
| MAX485 / SP485 | TTL ⇄ RS-485 | 1 发 1 收 | 差分半双工接口 |
| CH340 | USB ⇄ TTL 串口 | 1 | USB 转串口 |
| CP2102 | USB ⇄ TTL 串口 | 1 | USB 转串口 |
| FT232 | USB ⇄ TTL 串口 | 1 | 高性价比 USB 转串口 |

## 硬件流控 (RTS/CTS)

当一方处理数据的速度跟不上接收速度时，可通过硬件流控信号暂停对方发送。

| 信号 | 全称 | 方向 | 说明 |
|------|------|------|------|
| TX | Transmit | 本地 → 远端 | 数据发送 |
| RX | Receive | 远端 → 本地 | 数据接收 |
| RTS | Request to Send | 本地 → 远端 | 请求发送（本地准备好） |
| CTS | Clear to Send | 远端 → 本地 | 允许发送（对方准备好） |

当接收缓冲区将满时，接收方拉低 CTS 通知对方暂停发送。除此之外，还有 **XON/XOFF** 软件流控（发送特殊字符控制）。

## DB9 接口定义

标准 RS-232 公头/母头 DB9 引脚（PC 侧为公头）：

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1 | DCD | 载波检测 |
| 2 | RXD | 接收数据 |
| 3 | TXD | 发送数据 |
| 4 | DTR | 数据终端就绪 |
| 5 | GND | 信号地 |
| 6 | DSR | 数据设备就绪 |
| 7 | RTS | 请求发送 |
| 8 | CTS | 允许发送 |
| 9 | RI | 振铃指示 |

**最简单的三线连接**（交叉连接）：GND—GND、TXD—RXD、RXD—TXD。

## 常用接法示例

### 三线制（无流控）

```
MCU侧          设备侧
 TX ─────────── RX
 RX ─────────── TX
 GND ────────── GND
```

### 五线制（带硬件流控）

```
MCU侧          设备侧
 TX ─────────── RX
 RX ─────────── TX
 RTS ────────── CTS
 CTS ────────── RTS
 GND ────────── GND
```

## USB 转串口

现代 PC 普遍不再配备原生 RS-232 接口（DB9 口），而是通过 **USB 转串口** 芯片解决。

常见芯片方案：
- **CH340** (南京沁恒)：广泛使用，驱动易获取
- **CP2102 / CP2104** (Silicon Labs)：稳定性好
- **FT232** (FTDI)：高端，自带唯一序列号
- **PL2303** (Prolific)：老牌芯片，兼容性好

这些芯片在 PC 端表现为虚拟 COM 口（Virtual COM Port, VCP），应用程序无需修改即可像操作传统串口一样操作它们。

## 常用调试工具

- **SSCOM / 串口调试助手**：Windows 图形化串口工具
- **PuTTY**：支持串口、SSH 等多种终端连接
- **minicom / picocom**：Linux 终端下的串口工具
- **screen**：Linux 下 `screen /dev/ttyUSB0 115200`
- **逻辑分析仪**：通过物理层波形排查串口通信故障
