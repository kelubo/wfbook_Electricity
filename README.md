# README

**wfbook_电学** 是从 wfbook 主库拆分出的电学专题知识库，涵盖电工基础、电子技术、电磁学、数字电路、强弱电系统、仪器仪表以及连接器等内容，旨在构建一个结构清晰、内容可靠的电学知识体系。

## 内容结构

```
wfbook_电学/
├── 0_电.md                  # 导体/绝缘体/半导体概述，电子技术发展史
├── 1_电路.md                # 电路组成、串并联、模拟与数字电路
├── 2_电流.md                # 电流概念、分类、测量、效应
├── 3_电压.md                # 电位、电压、电动势、安全电压
├── 4_电阻.md                # 电阻概念、色环、阻值表、串并联
├── 5_定律.md                # 欧姆定律、基尔霍夫、戴维南等基本定律
├── 6_电功率.md              # 电功、直流/交流功率、功率因数
├── 7_capacitor电容.md       # 电容器原理、参数、串并联、材质
├── 8_inductor电感.md        # 电感器原理、感抗、储能、分类
├── 半导体.md                # PN 结原理、N/P 型半导体、掺杂
├── transistor三极管.md       # BJT 原理、三种工作状态、检测方法
├── 符号.md                  # 电工电子标准图形符号与文字符号
├── 交流电.md                # 正弦波参数、相位、三相交流、波形
├── 接地.md                  # 接地概念、类型、方式、地环问题
├── 信号.md                  # 信号分类、波形、时域/频域分析
├── RS485.md                 # RS-485 电气特性、拓扑、终端匹配
├── 电磁/                    # 磁铁、电磁、铁磁材料、变压器
├── 电子/                    # 串口通信、电磁波、电磁辐射
├── 强电/                    # 安全电压、电线、蓄电池、用具
├── 弱电/                    # 楼宇智能化技术
├── 数字电路/                # 门电路、组合/时序逻辑
├── 连接器/                  # 各类连接器图片
├── 仪器仪表/                # 钳形表、调压变压器等仪表
└── Images/                  # 图片资源
```

## 阅读建议

- 从 **0_电.md** 开始，了解基本概念和电子技术发展脉络
- 再读 **1_电路.md** ~ **6_电功率.md**，建立基础电路分析能力
- 接着读 **半导体.md** → **transistor三极管.md**，掌握半导体器件基础
- 深入 **7_capacitor电容.md** 和 **8_inductor电感.md**，理解储能元件
- 了解 **交流电.md** 和 **三相交流** 的入门知识
- 子目录按需查阅：数字电路、强电、弱电、仪器仪表等
